# TP6 Mini Project Kotlin Console

## Deskripsi Masalah
Proyek ini dibuat sebagai latihan pengembangan aplikasi Kotlin Console dengan menggunakan Git dan GitHub. Tujuannya adalah memahami penggunaan version control dalam proses pengembangan program.

## Identitas Siswa
Nama: Edward Galys Suganda
Kelas: XI TIP 1

## Nama Proyek
TP6_MiniProject_EdwardGalysSuganda

## Tujuan
Menerapkan penggunaan Git untuk mencatat perubahan kode, mengelola repository, dan membuat commit secara bertahap.

## Teknologi
- Kotlin
- IntelliJ IDEA
- Git
- GitHub

## Fitur Program
- Menampilkan nama proyek.
- Menampilkan perulangan angka.
- Menjalankan program melalui Kotlin Console.

## Cara Menjalankan
1. Buka proyek melalui IntelliJ IDEA.
2. Buka file src/Main.kt.
3. Jalankan program menggunakan tombol Run.
4. Lihat hasil program pada terminal.

## Riwayat Pengembangan
- Membuat struktur awal mini project.
- Menambahkan dokumentasi proyek.
- Membuat program Kotlin sederhana.
